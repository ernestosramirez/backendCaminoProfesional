# Camino Profesional — Backend

Lógica del lado del servidor y API de Camino Profesional, encargada de la gestión de usuarios, roles, catálogo y persistencia de datos.

Enlace al Frontend: [frontendCaminoprofesional](https://github.com/ernestosramirez/frontendCaminoprofesional)

---

Funcionalidades
- Autenticación: Registro e inicio de sesión de usuarios.
- Panel Admin: Endpoints protegidos para la asignación y gestión de roles de administrador.
- Tienda: Gestión y consulta de datos del catálogo de libros.
- Base de datos: Persistencia y consultas en MySQL.

---

Tecnologías
- PHP, MySQL, Apache y Git/GitHub.
